## Recommended order for creating the first stories

Start with these stories first:

1. `SCOPE-02` — Select the pilot process.
2. `SCOPE-04` — Approve supported questions.
3. `SCOPE-05` — Approve unsupported questions.
4. `DATA-06` to `DATA-17` — Resolve identifiers, relationships, versions and freshness.
5. `CONTRACT-01` to `CONTRACT-14` — Define common contracts.
6. `KB-01` to `KB-20` — Build the first knowledge package.
7. `REG-01` to `REG-14` — Build the capability registry.
8. `GATEWAY-01` to `GATEWAY-11` — Build controlled tool execution.
9. `VAR-01` to `VAR-14` — Complete the first variant vertical slice.
10. Add membership and journey capabilities after the variant flow works end to end.
